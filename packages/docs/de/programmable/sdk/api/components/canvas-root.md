# CanvasRoot

`CanvasRoot` ist das strukturelle Canvas-Primitiv in `@openweave/react`.

Verwenden Sie es, wenn Sie SDK-bereitgestellte Canvas-Struktur und Kontext mit app-eigenem Layout und Styling möchten.

## Verwandte APIs

- [useCanvas](../hooks/use-canvas)
- [useCanvasInput](../hooks/use-canvas-input)
- [useTextEdit](../hooks/use-text-edit)
