# ToolbarRoot

`ToolbarRoot` ist das headless Toolbar-Primitiv aus `@openweave/react`.

Verwenden Sie es, wenn Sie wiederverwendbare Toolbar-Struktur und Kontext mit Ihren eigenen Schaltflächen, Styling und Layout möchten.

## Verwandte APIs

- [useEditorCommands](../hooks/use-editor-commands)
- [useSelectionCapabilities](../hooks/use-selection-capabilities)
