# CanvasRoot

`CanvasRoot` to strukturalny prymityw kanvasu w `@openweave/react`.

Użyj go, gdy chcesz strukturę kanvasu i kontekst dostarczane przez SDK, ale layout i stylowanie należące do aplikacji.

## Powiązane API

- [useCanvas](../hooks/use-canvas)
- [useCanvasInput](../hooks/use-canvas-input)
- [useTextEdit](../hooks/use-text-edit)
